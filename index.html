2.2 值类型和引用类型
C# 中的每个类型都是 值类型 或 引用类型。 此区别决定了变量存储数据的方式和分配的工作原理。
值类型 - 直接保存其数据。 将值类型分配给新变量时，运行时将复制数据。 对一个变量的更改不会影响另一个变量。 结构、枚举和内置数值类型都是值类型。
引用类型 - 保存对托管堆上对象的引用。 将引用类型分配给新变量时，这两个变量都指向同一对象。 通过一个变量进行的更改在另一个变量可见。 类、数组、委托和字符串是引用类型。

2.4 自定义类型
类 - 用于建模行为和复杂对象的引用类型。 支持继承和多态性。
结构 - 小型轻型数据的值类型。 每个变量都有自己的副本。
记录 - 拥有编译器生成的“相等性”的类或结构，ToString，并通过with表达式实现非破坏性修改。
接口 - 定义任何类或结构都可以实现的成员的协定。
枚举 - 命名的整数常量集，例如星期几或文件访问模式。
元组 - 轻量级结构类型，用于对相关值进行分组，而无需定义命名类型。
泛型 - 通过诸如 List 和 Dictionary 这样的类型参数化结构，在重用相同逻辑以处理不同类型时提供类型安全性。
2.5 选择哪种自定义类型
元组 - 不需要命名类型或行为的值的临时分组。
struct 或 record struct - 小型数据、值语义或不可变性。 记录结构添加基于值的相等性和 with 表达式。
record class - 主要是基于值的相等性数据， ToString以及非破坏性突变。 支持继承。
class - 复杂行为、多态性或可变状态。 大多数自定义类型都是类。
interface - 不相关类型可以实现的接口。 定义功能而不是标识。
enum - 一组固定的命名常量，例如状态代码或选项。
2.6 控制台的基本输入输出

    public static async Task Main(string[] args)
    {
        Console.OutputEncoding = Encoding.UTF8;

        Console.WriteLine("=== 控制台 基本输入/输出 示例 ===\n");

        // 1) 简单输出
        Console.Write("1) 请看这是一行输出（不换行）...");
        Console.WriteLine("  这是紧接着的 Console.WriteLine 输出。");

        // 2) 读取整行文本（Console.ReadLine）
        Console.WriteLine();
        Console.Write("2) 请输入你的姓名，然后按回车: ");
        string? name = Console.ReadLine();
        Console.WriteLine($"你好，{name ?? "匿名"}！");

        // 3) 读取单个键（Console.ReadKey）
        Console.WriteLine();
        Console.Write("3) 按任意键继续（该键不会回显）...");
        Console.ReadKey(intercept: true); // 不在控制台回显按键
        Console.WriteLine(" 已继续。\n");

        // 4) 读取密码（通过 ReadKey 循环并回显 '*')
        Console.WriteLine("4) 请输入密码（回车结束，回显为 *）：");
        string password = ReadPassword(mask: '*');
        Console.WriteLine();
        Console.WriteLine($"你输入的密码长度：{password.Length}\n");

        // 5) 解析数值输入（TryParse，安全）
        Console.Write("5) 请输入一个整数: ");
        string? intText = Console.ReadLine();
        if (intText is not null && int.TryParse(intText, NumberStyles.Integer, CultureInfo.InvariantCulture, out int n))
        {
            Console.WriteLine($"成功解析为整数：{n}");
        }
        else
        {
            Console.WriteLine("无法解析为整数（请检查输入）。");
        }

        // 6) 读取多值（逗号或空格分隔），并做格式化输出
        Console.WriteLine();
        Console.Write("6) 输入多个浮点数（用空格或逗号分隔），回车结束: ");
        string? many = Console.ReadLine();
        if (!string.IsNullOrWhiteSpace(many))
        {
            string[] parts = many.Split(new[] {',', ' '}, StringSplitOptions.RemoveEmptyEntries);
            Console.WriteLine("解析并格式化输出：");
            foreach (var p in parts)
            {
                if (double.TryParse(p, NumberStyles.Float | NumberStyles.AllowThousands, CultureInfo.InvariantCulture, out double d))
                {
                    Console.WriteLine($"  原始: {p} -> 双精度: {d:N4}");
                }
                else
                {
                    Console.WriteLine($"  无法解析: {p}");
                }
            }
        }

        // 7) 演示命令行参数
        Console.WriteLine("7) 命令行参数示例：");
        if (args.Length == 0)
            Console.WriteLine("  未提供命令行参数。");
        else
            Console.WriteLine($"  参数数量: {args.Length} -> [{string.Join(", ", args)}]");

        // 结束
        Console.WriteLine("示例结束。按任意键退出...");
        Console.ReadKey(intercept: true);
        return 0;
    }

    // 从控制台读取密码，回显掩码字符
    static string ReadPassword(char mask = '*')
    {
        var sb = new StringBuilder();
        while (true)
        {
            var key = Console.ReadKey(intercept: true);
            if (key.Key == ConsoleKey.Enter)
            {
                break;
            }
            else if (key.Key == ConsoleKey.Backspace)
            {
                if (sb.Length > 0)
                {
                    sb.Length--;
                    // 移除屏幕上的一个掩码字符
                    Console.Write("\b \b");
                }
            }
            else if (!char.IsControl(key.KeyChar))
            {
                sb.Append(key.KeyChar);
                Console.Write(mask);
            }
        }
        return sb.ToString();
    }

3.7 成员访问和空值条件运算符和表达式
. （成员访问）：访问命名空间或类型的成员。
[] （数组元素或索引器访问）：访问数组元素或类型索引器。
?. 和 ?[] （null 条件运算符）：仅当操作数为非 null 时，才执行成员或元素访问操作。
如果 a 的计算结果为 null，则 a?.x 或 a?[x] 的结果为 null。
如果 a 的计算结果为非 null，则 a?.x 或 a?[x] 的结果将分别与 a.x 或 a[x] 的结果相同。
() （调用）：调用访问的方法或调用委托。() 的其他用法：可以使用括号来调整表达式中计算操作的顺序。强制转换表达式，其执行显式类型转换，也可以使用括号。
^ （结尾索引）：指示元素位置来自序列的末尾。
.. （range）：指定可用于获取序列元素范围的索引范围。
