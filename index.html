    Windows下即使启用了VPN等翻墙工具rustup的下载仍然缓慢，可能是因为VPN的配置对下载通道无效。
    rustup支持通过环境变量来设置代理（它底层使用curl或类似机制），以下是具体操作：
    1. 使用命令提示符 (CMD) 配置：
    
set https_proxy=http://127.0.0.1:10808
set http_proxy=http://127.0.0.1:10808  (可选，如果需要HTTP代理)
    2. 使用PowerShell配置：
    
$env:https_proxy = "http://127.0.0.1:10808"
$env:http_proxy = http://127.0.0.1:10808"  (可选)
    3. 如果你的代理需要认证，格式为 `http://username:password@your-proxy-ip:port`。以上设置只限于当前会话。
    4. 然后运行  rustup update 命令升级。
    5. 如果代理设置后还是报错（如SSL协议错误），尝试省略协议前缀（例如 `set https_proxy=your-proxy-ip:port`）。
